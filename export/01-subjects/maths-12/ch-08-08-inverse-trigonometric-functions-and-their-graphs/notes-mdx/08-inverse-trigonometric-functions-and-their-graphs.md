# 8.1 Exercise 8.1

# **Key Concepts**

This exercise focuses on the following concepts:

* **Principal Value Ranges**: Understanding the restricted codomains for inverse trigonometric functions to ensure they remain functions.

* **Inverse Trigonometric Functions**: Evaluating $\arcsin(x)$, $\arccos(x)$, $\arctan(x)$, and their reciprocal counterparts.

* **Exact Values**: Utilizing knowledge of standard angles ($0, \frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}, \frac{\pi}{2}$) and the unit circle.

* **Algebraic Summation**: Combining multiple inverse trigonometric values into a single real number or angle.

* **Numerical Approximation**: Using calculators to find non-standard angles in both degrees and radians.

---

# **Important Formulas**

Below are the key formulas used in this exercise:

| Function | Principal Value Range (Output) | Domain (Input) |
| :--- | :--- | :--- |
| $y = \arcsin(x)$ | $[-\frac{\pi}{2}, \frac{\pi}{2}]$ | $[-1, 1]$ |
| $y = \arccos(x)$ | $[0, \pi]$ | $[-1, 1]$ |

| $y = \arctan(x)$ | $(-\frac{\pi}{2}, \frac{\pi}{2})$ | $\mathbb{R}$ |

| $y = \text{arccsc}(x)$ | $[-\frac{\pi}{2}, \frac{\pi}{2}], y \neq 0$ | $(-\infty, -1] \cup [1, \infty)$ |
| $y = \text{arcsec}(x)$ | $[0, \pi], y \neq \frac{\pi}{2}$ | $(-\infty, -1] \cup [1, \infty)$ |

| $y = \text{arccot}(x)$ | $(0, \pi)$ | $\mathbb{R}$ |

---

# **Summary**

This exercise covers the foundational skills required to work with inverse trigonometric functions. The primary learning objective is to distinguish between the infinite possible angles that satisfy a trigonometric equation and the unique **principal value** defined by mathematical convention. Key strategies include identifying the sign of the input to determine the correct quadrant and memorizing the standard unit circle values to solve expressions without digital aids.

For non-standard values, the exercise emphasizes the correct use of calculators for decimal approximation.

# **Key Concepts**

This exercise focuses on the following concepts:

- **Addition and Subtraction Theorems:** Applying formulas for $\sin^{-1}$, $\cos^{-1}$, $\tan^{-1}$, and $\cot^{-1}$ to combine multiple terms.
- **Reciprocal Relationships:** Using the relationships between $\csc^{-1}$, $\sec^{-1}$, $\cot^{-1}$ and their primary counterparts ($\sin^{-1}$, $\cos^{-1}$, $\tan^{-1}$).
- **Identity Verification:** Proving that the sum or difference of specific inverse trigonometric values equals a constant (e.g., $\pi/2$, $\pi/4$).
- **Negative Arguments:** Handling properties like $\sin^{-1}(-x) = -\sin^{-1}(x)$ and $\cos^{-1}(-x) = \pi - \cos^{-1}(x)$.

- **Algebraic Substitution:** Evaluating complex inverse trigonometric expressions by substituting specific values for $x$.

---

# **Important Formulas**

Below are the key formulas used in this exercise:

| Function | Addition / Subtraction Formula |
| :--- | :--- |
| **Sine** | $\sin^{-1} x \pm \sin^{-1} y = \sin^{-1}\left(x \sqrt{1-y^{2}} \pm y \sqrt{1-x^{2}}\right)$ |

| **Cosine** | $\cos^{-1} x \pm \cos^{-1} y = \cos^{-1}\left(xy \mp \sqrt{(1-x^{2})(1-y^{2})}\right)$ |

| **Tangent** | $\tan^{-1} x \pm \tan^{-1} y = \tan^{-1}\left(\frac{x \pm y}{1 \mp xy}\right)$ |

| **Cotangent** | $\cot^{-1} x + \cot^{-1} y = \cot^{-1}\left(\frac{xy-1}{x+y}\right)$ |
| **Secant** | $\sec^{-1} x + \sec^{-1} y = \cos^{-1}\left(\frac{1-\sqrt{(x^{2}-1)(y^{2}-1)}}{xy}\right)$ |
| **Cosecant** | $\operatorname{cosec}^{-1} x + \operatorname{cosec}^{-1} y = \sin^{-1}\left[\frac{\sqrt{y^{2}-1}+\sqrt{x^{2}-1}}{xy}\right]$ |

---

# **Summary**

This exercise provides practice in manipulating inverse trigonometric functions through their respective addition and subtraction laws. The primary strategy involves identifying the appropriate formula based on the function type and simplifying the resulting algebraic expression. For functions like $\sec^{-1}$ and $\csc^{-1}$, it is often helpful to convert them into $\cos^{-1}$ and $\sin^{-1}$ forms.

A common pattern in these problems is the verification of the identity $\sin^{-1} x + \cos^{-1} x = \pi/2$ or similar results involving complementary angles. When solving equations, ensure that the final result is checked against the principal value branches of the inverse functions.
